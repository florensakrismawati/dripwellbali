DRIPWELL BALI — SEO-FRIENDLY HTML WEBSITE

Files:
- index.html       Main website; all UI logic is inline and works without a build step.
- assets/          Logo, favicon, and image assets.
- robots.txt       Basic crawler instructions.

Features:
- Responsive desktop/mobile navigation
- Treatment category tabs
- Treatment/package cards with booking buttons
- Area selector
- FAQ accordion
- Booking form that opens a pre-filled WhatsApp message
- SEO title/description, Open Graph/Twitter metadata
- MedicalBusiness JSON-LD structured data
- Keyboard focus states, skip link, reduced-motion support

Deployment:
Upload index.html, robots.txt, and the assets folder to any static hosting service.
No Node.js, framework, database, or build process is required.
